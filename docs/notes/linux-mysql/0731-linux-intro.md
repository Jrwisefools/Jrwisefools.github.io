### 安装环境
VMware Workstation虚拟化软件,允许用户在一台物理机器上创建和运行多个完整的虚拟机
虚拟机是相互独立的，（宿主机）不会影响主机

#### 虚拟机网络模式
1. 桥接网络
虚拟机的地址和主机的地址在同一个网段
ip字段少容易冲突，同一个网段内的其他设备也可以之间访问你的虚拟机,不安全
2. 网络地址转换模式（NAT模式）
虚拟机和主机不在同一个网段
会装一个虚拟网卡(VMnet8)，虚拟机和vmnet8在同一个网段
自己的主机和其他人的主机是可以通过vmnet8和虚拟机进行交互

3. 仅主机模式
虚拟机和VMNET1在同一个网段
主机通过远程访问工具操作虚拟机
（通过ip来判断操作哪一台虚拟机）
所以得将虚拟机的ip固定
只有自己的主机才可以和虚拟机进行交互

## 文件目录类
1. pwd 显示当前工作目录的绝对路径
2. ls 列出列表内容
    -a 全部文件包括隐藏文件
    -l 长数据串列出，包含文件属性权限
    -R 列出目录下所有子文件目录和文件
    注:ll是ls-al的别名，可以使用ll来查看目录下的所有文件
-是表示文件，d文件夹，还有l软连接
接在后面的是权限，后面数字是有几个文件

3. cd 切换目录 
cd：切换路径  
cd 绝对路径->从根目录/ 开始  
cd 相对路径  
cd~或者cd 回到自己的家目录  
cd- 回到上次所在的目录  
cd.. 回到上一个目录  
cd -P 跳转到实际物理路径，而非快捷方式路径   
### mkdir 创建目录
-P 创建多级目录   
sudo mkdir mytest/a 在已有的mytest下创建a    
sudu mkdir mytest -P mytest2/b 在当前目录创建目录mytest2和其目录下创建b    

### touch
创建文件
sudo touch {a..z}.txt
若用makedir 创建a.txt还是创建的文件夹
Linux是通过指令来判断你要创建什么

### cp 复制文件和目录
cp a.txt a2.txt
在当前目录下复制一个a.txt成b.txt
（cp只能复制文件不能复制目录）
cp -r 才可以复制目录

### mv 移动文件或目录（剪切）
1. mv oldNameFile newNameFile   --->剪切变新文件名
2. mv/XXX/movefile/targetFolder --->把文件移到目标目录中，文件名不变

### rm删除文件或目录
-r 删除目录和其中的文件
-f 强制执m行删除
-v 显示指令的详细执行
rm -rf *.txt
匹配当前目录下所有后缀为.txt 的文件
*** 千万别加斜杠不然删除根目录
### cat 查看文件内容
    -n 显示所有行的行号
### tail 输出文件尾部内容
    默认查看后十行
    -n 数字，显示倒数数字行数的内容
    -f 实时查看文件最新追加的内容
### echo 输出内容到控制台
    \\输出本身
    \n 换行符号
    \t 制表符
    注意：要加-e ""，不然就原样输出
### >和 >>输出重定向
    >  覆盖写入
    >> 接着写入 
### ln 软连接
删除时候最后加了斜杠就是删文件
不加斜杠是删软连接

### history
查看历史指令

## VI/VIM编辑器
vim有三种模式
1. 一般模式（查看模式）
执行vim指令

2. 编辑模式：编辑内容
在一般模式下输入i即可进入编辑模式,输入Esc及可回退至一般模式

3. 命令模式：选择保存模式及退出模式
在一般模式下输入“:”冒号即可以进入命令模式，同样Esc回到一般模式
