# BOM：浏览器对象模型
## 本章内容

- window对象
- location对象
- sessionStorage和localStorage对象

## BOM对象介绍

- 概述
  - BOM(Browser Object Model)：浏览器对象模型。
  - 将浏览器的各个组成部分封装成不同的对象，方便我们进行操作。
- 分类
  - window对象
    - 表示浏览器中打开的窗口
  - location对象
    - 包含有关当前 URL 的信息
  - history对象
    - 包含当前访问过的URL
  - screen对象
    - 包含有关客户端显示屏幕的信息
  - navigator对象
    - 有关浏览器的信息

## window对象

- 方法说明

  | 方法           | 说明                                   |
  | -------------- | -------------------------------------- |
  | setTimeout()   | 在指定的毫秒数后调用函数               |
  | clearTimeout() | 取消由 setTimeout() 方法设置的 timeout |
  | setInterval()  | 按照指定的周期（以毫秒计）来调用函数   |
  | setInterval()  | 取消由 setInterval() 设置的 interval   |

- 需求

  - 在页面上动态显示时间

- 代码实现

  ```html
  <html lang="en">
  <head>
      <meta charset="UTF-8">
      <title>window对象练习</title>
      <script>

          var interval ;
          window.onload = function () {
              showTime();

              interval = window.setInterval("showTime()", 1000);
          }

          function showTime() {
              var spanEle = document.getElementById("time");
              var date = new Date();
              var timeStr = date.getFullYear() + "年" + (date.getMonth() + 1) + "月" + date.getDate() + "   " +
                  date.getHours() + ":" + date.getMinutes() + ":" + date.getSeconds();
              spanEle.innerText = timeStr;
          }

          function pause() {
              window.clearInterval(interval);
          }

          function resume() {
              interval = window.setInterval("showTime()", 1000);
          }

      </script>
  </head>
  <body>

  <span id="time"></span><br>
  <button onclick="pause()">暂停</button>
  <button onclick="resume()">恢复</button>

  </body>
  </html>
  ```

## sessionStorage和localStorage对象

- 概述

  - 用于存储数据的容器

- sessionStorage

  - 只能在一个窗口中共享数据

- localStorage

  - 可以在多个窗口中共享数据
  - 即使浏览器关闭，数据依然存在

- 方法说明

  | 方法               | 说明         |
  | ------------------ | ------------ |
  | setItem(key,value) | 存储指定数据 |
  | getItem(key)       | 获取指定数据 |
  | removeItem(key)    | 移除指定数据 |
  | clear()            | 清空所有数据 |

- 代码实现

  ```html
  <body>

  <button onclick="fn1()">sessionStorage存储</button>
  <button onclick="fn2()">localStorage存储</button><br>
  <button onclick="fn3()">sessionStorage移除</button>
  <button onclick="fn4()">localStorage移除</button><br>
  <button onclick="fn5()">sessionStorage清空</button>
  <button onclick="fn6()">localStorage清空</button><br>
  <script>

      function fn1() {
          sessionStorage.setItem("msg1", "helloworld1");
      }

      function fn2() {
          localStorage.setItem("msg2", "helloworld2");
      }

      function fn3() {
          sessionStorage.removeItem("msg1");
      }

      function fn4() {
          localStorage.removeItem("msg2");
      }

      function fn5() {
          sessionStorage.clear();
      }

      function fn6() {
          localStorage.clear();
      }

  </script>
  </body>
  ```

  ```html
  <body>

  <button onclick="fn1()">sessionStorage获取</button>
  <button onclick="fn2()">localStorage获取</button>
  <script>

      function fn1() {
          console.log(sessionStorage.getItem("msg1"))
      }

      function fn2() {
          console.log(localStorage.getItem("msg2"))
      }
  </script>
  </body>
  ```

- 注意事项

  - sessionStorage和localStorage只能存储字符串，如果想要存储对象信息
  - 在存储时，需要将js对象转换为json字符串，然后存储json字符串；
  - 在取出时，需要将json字符串转换为js对象，然后进行使用
